# Nero + DH116 小型 VLA 数据闭环

## 阶段目标

这一阶段不直接训练抓取。现有纯物理 Lift 基线虽然在第 500 步发生接触，但方块抬升高度为 0；默认演示依靠接触后的状态稳定器才能成功。把这类轨迹当作“成功抓取”训练数据会掩盖真实物理失败。

当前阶段改为两个可验证的视觉语言到达指令：

- `move above the cube`：移动到随机方块上方 12 cm；
- `return home`：返回 Nero 七轴零位。

它保留了完整数据闭环：随机场景、专家示范、RGB 与本体状态、语言条件、动作学习、留出场景闭环评测。DH116 在本阶段保持张开，作为组合机器人末端的一部分参与仿真。

## 为什么不算作弊

程序用以下硬约束隔离真值：

1. 环境设置 `use_object_obs=False`，策略收到的 observation 中没有 `cube_pos` 或其他物体状态；
2. 策略编码器只接收 `agentview_image`、`robot0_joint_pos`、`robot0_eef_pos` 和语言指令；RGB 预处理仅计算普通缩放像素与红色响应矩，不读取分割、geom id 或仿真坐标；
3. 方块真值仅供采集专家生成动作和视觉定位监督标签，以及评测器在策略执行结束后计算误差；它不进入推理 observation；
4. 训练集和验证集按 episode 划分，不把同一轨迹的相邻帧拆到两侧；
5. 测试使用与采集不同的随机种子；
6. 推理动作全部通过 `env.step()` 执行，不修改方块位置、速度或接触状态；
7. 不使用 `ContactGraspStabilizer`、焊接约束或分割图。
8. 方块在 XY 平面 ±8 cm 范围采样，到达阈值收紧为 2 cm；另用完全相同的留出种子做全黑 RGB 消融，检查策略是否真的使用视觉。

专家拥有仿真真值并不等于策略作弊。这里相当于教师在采集阶段知道答案；关键是保存给学生的输入以及部署时的输入均不包含答案。

## 数据和模型

脚本为 [nero_dh116_vla.py](nero_dh116_vla.py)。为了能在当前基础环境运行，不增加 PyTorch 和 h5py 依赖：

- 数据使用压缩 NPZ；
- 环境渲染 128×128 `agentview`，数据保存为 32×32 RGB；编码器从 RGB 直接计算归一化红色质心，并使用二次特征做 XY 标定；
- 本体状态包含七轴位置和末端三维位置；
- `return home` 明确屏蔽 RGB，只使用本体状态，避免小数据把背景偶然相关性当成回家依据；
- 动作为 Nero `JOINT_POSITION` 控制器原生的七轴绝对目标；到达专家每步 IK 更新最多 ±0.035 rad，回家目标直接是七轴零位；
- 每条采集指令记录 70 步；闭环评测允许执行 90 步，使工作空间边缘目标有足够时间在不放宽 2 cm 阈值的前提下收敛；
- 首帧 RGB 的红色像素质心经过训练集标定为方块 XY，运行时锁存该视觉估计；
- `move above the cube` 用视觉估计和机器人自身 Jacobian 生成绝对关节目标，`return home` 选择已知零位目标；
- 数据采集时对实际执行动作加入小噪声，但监督标签保持为专家动作，使策略见到轻微偏离后的恢复状态。

这不是通用大模型，而是可解释的模块化 VLA 基线。语言选择技能，视觉定位目标，机器人运动学把目标转换为动作。它的价值是快速验证视觉、语言、动作、监督标签隔离和闭环评测是否真正连通。

## 运行方式

完整执行：

```bash
python tests/dh116/nero_dh116_vla.py all
```

也可以分阶段运行：

```bash
python tests/dh116/nero_dh116_vla.py collect
python tests/dh116/nero_dh116_vla.py train
python tests/dh116/nero_dh116_vla.py evaluate
```

默认产物位于 `tests/dh116/vla_artifacts/`：

- `nero_dh116_reach_dataset.npz`：训练数据；
- `nero_dh116_reach_locator.npz`：RGB 方块定位标定模型；
- `latest_report.json`：采集、离线验证和闭环评测记录。

## 完成条件

阶段任务只有同时满足以下条件才算完成：

- 两条指令在留出随机种子上均完成闭环运行；
- 按 episode 留出的方块 XY 视觉定位最大误差小于 1 cm；
- `move above the cube` 的末端目标误差小于 2 cm；
- `return home` 的七轴联合误差小于 0.12 rad；
- 正常 RGB 到达成功率必须明显高于全黑 RGB 消融；
- 报告确认无稳定器、无物体状态改写、策略无物体真值；
- 代码、报告和技术文档一起提交并推送。

若学习策略没有达到阈值，应保留真实失败记录并继续改进，不能用专家动作替换预测动作，也不能放宽指标来宣称完成。
